# Не спать при закрытой крышке

Обычная кнопка «Не давать Mac засыпать» держит компьютер от сна по простою, но закрытая
крышка ноутбука усыпляет его всё равно — и агенты в сессиях останавливаются. Этот режим
отключает сон целиком, в том числе по крышке: ноутбук можно закрыть и унести, работа
продолжится.

Доступен, только если хост — Mac. На Linux и в гостевом доступе его нет.

English version: [lid-awake.md](lid-awake.md).

## Как пользоваться

- **Нажатие** на кнопку с чашкой — прежнее поведение: не засыпать по простою.
- **Удержание** кнопки (около 0,6 с) включает режим «не спать и с закрытой крышкой».
  Кнопка начинает мигать жёлтым и мигает, пока режим включён. Выключает его любое
  нажатие на мигающую кнопку — короткое или удержание.
- **Открыли крышку — режим выключился сам.** Режим включают перед тем, как закрыть
  ноутбук; когда крышку закрыли и снова открыли, он своё отработал.
- О каждом переключении — обычного режима, режима крышки и автоматического выключения —
  приложение сообщает всплывающим сообщением.

Кнопка находится в меню «⋯» на главной и в полосе действий окна сессий; в боковом режиме
на десктопе — прямо в шапке.

## Однократная настройка на Mac

Отключить сон по крышке может только root. Агент работает от вашего пользователя, поэтому
ему нужно разрешение выполнять без пароля две точные команды:

```
/usr/bin/pmset -a disablesleep 0
/usr/bin/pmset -a disablesleep 1
```

Выполните на Mac:

```bash
npx termhub lid-awake
```

Команда проверит, выдано ли разрешение, и если нет — напечатает строку, которую нужно
выполнить один раз (она создаёт файл `/etc/sudoers.d/termhub-lidawake` и проверяет его
`visudo`). Перезапускать агент после этого не нужно.

Пока разрешения нет, удержание кнопки ничего не меняет, а приложение пишет, что нужна
настройка.

Отозвать разрешение:

```bash
sudo rm /etc/sudoers.d/termhub-lidawake
```

## Что стоит знать

- **Нагрев.** Закрытый работающий ноутбук в сумке греется. Режим рассчитан на стол и
  подставку; поэтому он и выключается сам при открытии крышки, а кнопка мигает.
- **Настройка системная.** Пока режим включён, Mac не уснёт вообще — ни по крышке, ни по
  простою, ни по кнопке «Сон». Проверить вручную: `pmset -g | grep SleepDisabled`.
- **Режим не переживает агент.** При остановке агента сон возвращается. Если агент упал,
  настройка вернётся при следующем его запуске.
- **Вернуть вручную:** `sudo pmset -a disablesleep 0`.
- **Настольные Mac** (без крышки): режим включается и работает как «не спать вообще», но
  сам не выключается — выключайте удержанием.

## Как это устроено

Механизм взят из утилиты [Fermata](https://github.com/iccir/Fermata): системная настройка
питания `SleepDisabled`. Fermata ставит её приватным вызовом из привилегированного
помощника; TermHub ставит ту же настройку штатной командой `pmset -a disablesleep`,
вызывая её через `sudo -n`. Крышку агент опрашивает раз в две секунды
(`ioreg -r -k AppleClamshellState`).

Решение и отвергнутые варианты — [ADR 0036](adr/0036-lid-awake-via-pmset-and-sudoers.md).
