# Имена сессий

Имя существующей сессии — буквальная метка из списка tmux. Оно не является
адресом окна/панели, glob-шаблоном или внутренним ID. Агент и shell-команды
сравнивают метки целиком и передают tmux найденный `session_id` (`$N`).
Отсутствующая метка должна дать ошибку, даже если существует похожая сессия.

Для существующих сессий поддерживаются точки, пробелы, Unicode, длинные имена,
двоеточия, символы URL и имена, похожие на ID. Пустые метки и управляющие символы
отклоняются. Ограничение формы создания (ASCII, 40 символов) не применяется к
подключению, удалению, исходному имени переименования или гостевому scope.

LAN передаёт имя в query-параметре `name` у `/ws/term` и `DELETE /api/sessions`:
сегменты пути `.` и `..` нормализуются браузером. Старые маршруты с именем в пути
сохраняются для совместимости. В hash-маршрутах и JSON имя кодируется отдельно.

Переименование сохраняет введённую метку без очистки символов. `#` экранируется
для tmux format expansion, завершающая `;` — для парсера команд tmux, `--` завершает флаги rename-session. Новые метки с
обратной косой чертой отклоняются: tmux сам удваивает её при создании/переименовании.
Существующую такую сессию можно открыть, завершить или переименовать в другое имя.

Сборочные сессии скрываются по `@termhub_gradle_cmd`, а не по префиксу имени.
Запуск/остановка Gradle отклоняется при занятом служебном имени без этого признака.

Регрессии: sessions.tmux, bridge.tmux, tm-shell, tmux-session, server и gradle.tmux.
Живые проверки используют только изолированные тестовые сокеты.
