# 0042. Список слэш-команд — свой, со сверкой с тем, что показывает агент

Дата: 12.11.2026. Статус: принято.

## Задача

Набрав «/», человек хочет видеть команды агента с описаниями. Полный список знает только сам агент: встроенные команды, пользовательские, проектные, навыки. Подсказка должна работать, пока агент занят, и не требовать открытого терминала.

## Решение

Список собирает агент TermHub: встроенные команды — из профиля, пользовательские, проектные и навыки — с диска. Один раз на версию агента список сверяется с тем, что агент показывает по «/» сам: чат набирает «/» в пустой строке, листает всплывающий список с бюджетом на число страниц, возвращает строку пустой; недостающие команды добавляются с пометкой. Результат хранится на хосте и не пересобирается чаще раза в 10 минут при неудаче. Сверка идёт только когда агент ждёт ввода и его строка пуста. Замер таска 01 (D04): у Claude список по «/» — окно в 4–5 строк, полный список виден только прокруткой, поэтому сверка листает, а не снимает один кадр; на живом Claude она может не уложиться в 5 с — тогда ответ `verified: false`. Команду не из списка по-прежнему можно набрать и отправить как есть.

## Отвергнуто

- **Зеркалить всплывающий список агента на каждый ввод «/».** Нужен простой экран и пустая строка в каждый момент набора; во время работы агента подсказки бы не было, а набор в живую строку агента мешал бы человеку, работающему в терминале.
- **Только свой список, без сверки.** Встроенные команды агента растут с версиями; список из профиля молча отставал бы.
- **Только список агента.** Не даёт описаний пользовательских команд и навыков и недоступен, пока агент занят.

## Известные ограничения

- Сверка клавишами в живую строку агента — единственное место, где чат печатает в панель без просьбы человека; поэтому она только при пустой строке и свободном агенте, и сбой при этом не показывается как ошибка.
- Кэш на хосте привязан к версии: после обновления агента список неполон, пока не пройдёт сверка.
- Из-за окна в 4–5 строк у Claude сверка медленная и может остаться неподтверждённой.
