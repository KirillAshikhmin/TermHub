# 0006. JDK выбирается так же, как его выбирает IDEA (D01)

## Контекст

План исходил из того, что для воспроизводимого запуска достаточно выбрать `./gradlew`,
если он есть и исполняем, иначе `gradle` из PATH: wrapper фиксирует сборку проекта,
дальше окружение login-оболочки само разберётся.

## Решение

Одного wrapper'а мало — JDK выбирается явно, в порядке: `org.gradle.java.home` из
`<проект>/gradle.properties` → то же из `~/.gradle/gradle.properties` → `java.home` из
`<проект>/.gradle/config.properties` (это и есть `#GRADLE_LOCAL_JAVA_HOME`, на который
ссылается `.idea/gradle.xml`) → окружение login-оболочки как раньше. Выбранный JDK
передаётся и в чтение списка тасок, и в запуск сборки.

## Почему

Живая проверка 2026-08-22 на `~/AndroidStudioProjects/MyApplication`: `JAVA_HOME`
пользователя — JDK 25, wrapper проекта — Gradle 8.9, `tasks --all` падает с
«Unsupported class file major version 69»; с `java.home` из `.gradle/config.properties`
тот же вызов отрабатывает. Предположение плана оказалось неверным: wrapper фиксирует
версию Gradle, но не JDK, на котором Gradle исполняется, и у типичного
Android-проекта это разные вещи.

Отвергнут вариант считать это проблемой окружения и просить пользователя выставить
`JAVA_HOME`: вкладка не работала бы «из коробки» ровно на тех проектах, ради которых
затевалась, а IDEA от пользователя этого не требует.

Отвергнут и подбор JDK эвристикой по версии Gradle: это угадывание вместо чтения того,
что проект о себе уже записал.

## Последствия

Агент читает три файла свойств — два `gradle.properties` и `.gradle/config.properties`,
последний пишет IDEA и его формат нигде не зафиксирован как контракт; смена этого
формата тихо вернёт нас к JDK из окружения.

Проект, нигде не записавший свой JDK, по-прежнему собирается на `JAVA_HOME`
login-оболочки и по-прежнему может упасть на несовместимости — единственной подсказкой
остаётся текст ошибки Gradle во вкладке.

Выбор JDK обязан быть одним и тем же в чтении тасок и в запуске: расхождение даёт
худший из симптомов — «список читается, а сборка падает».
