# 0041. Профиль агента — данные, распознавание — чистая функция

Дата: 12.11.2026. Статус: принято.

## Задача

Чат опирается на то, как Claude Code и Codex рисуют экран и какие клавиши принимают. Оба обновляются часто, и любое обновление может сломать распознавание. Чинить это должно быть дёшево и без риска задеть логику.

## Решение

Всё, что зависит от конкретного агента, лежит данными в профиле: клавиши (отправка, прерывание, цикл режимов, перенос строки, стирание ввода), режимы, модели, встроенные команды, имена команд `model`/`compact`, признаки экранов, диапазон проверенных версий. Распознавание — чистая функция над строками экрана и профилем; она проверяется на снимках экранов (с версией агента и размером панели у каждого), без tmux и без живого агента. Новая версия агента чинится правкой профиля и добавлением снимка, а не логики.

## Отвергнуто

- **Распознавание кодом по каждому агенту отдельно.** Каждое обновление агента требовало бы править ветвления; проверить их без живого агента нельзя.
- **Читать состояние из заголовка панели и реестра агента.** Заголовок и реестр дают только грубое «работает/ждёт»; вопросы, режим и строка ввода видны только на экране.
- **Профиль в конфиге пользователя.** Правит владелец и ломает чат незаметно для проекта; профиль лежит в коде вместе со снимками, на которых он проверен.

## Известные ограничения

- Профиль всё равно описывает геометрию и слова экрана, то есть угадывает чужой интерфейс: обновление агента может сломать распознавание, и первым это заметит человек (отсюда ADR 0043 и счётчик сбоев).
- Данных много, и они расходятся с реальностью тихо: снимки надо обновлять с каждой проверенной версией.
- Подвал Codex настраивается владельцем (`/statusline`); нестандартный подвал — экран «не узнан», это допустимый исход, а не баг.
