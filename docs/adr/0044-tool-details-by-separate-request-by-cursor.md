# 0044. Подробности действия — отдельным запросом по курсору записи

Дата: 12.11.2026. Статус: принято.

## Задача

Действие агента показано строкой («Bash: npm test»), а по тапу должны раскрываться команда с выводом или diff правки. Лента намеренно отбрасывает вывод инструментов (`toolUseResult`, `function_call_output`): выводы бывают мегабайтами, а страница ленты ограничена 1 МиБ (ADR 0026), и результат лежит в другой строке транскрипта, иногда по другую сторону границы страницы.

## Решение

Страница ленты подробностей не несёт: у записи `tool` есть лишь пометка, что они существуют. По раскрытию чат запрашивает их отдельным запросом по курсору записи (`detail=<cursor>` того же запроса ленты, на обоих транспортах), агент сопоставляет вызов и результат по идентификатору и возвращает ввод, вывод или diff. Ответ ограничен 64 КиБ с пометкой об усечении; пока грузится — индикатор, не загрузилось — строка ошибки с «Повторить», остальной чат цел. Действие без результата (ещё идёт, прервано) так и называется, а не пустотой.

## Отвергнуто

- **Класть ввод и вывод в запись страницы.** Страница раздувается: пришлось бы взвешивать каждую запись по выводу и выкидывать записи ради предела, а большинство строк так никогда и не раскроют.
- **Склеивать вызов и результат на клиенте по `tool_use_id` из соседних страниц.** Пара может разъехаться по границе страницы или окна чтения 4 МиБ; клиент получил бы то половину, то ничего.
- **Читать транскрипт целиком ради вывода.** Живой транскрипт весит десятки мегабайт, целиком его не читают никогда.

## Известные ограничения

- Раскрытие — сетевой запрос: оффлайн раскрыть нельзя, а на медленном relay тап ждёт.
- Несколько инструментов в одной строке Claude делят курсор — по курсору отдаётся первый.
- Курсор может устареть (`cursor-stale`), как и у ленты; раскрытие тогда сообщает об этом строкой.
