# 0037. Картинка из буфера — файлом на хост, в терминал — путь

Дата: 12.11.2026. Статус: принято.

## Задача

Claude Code и Codex принимают картинку по Ctrl+V: читают буфер обмена машины, на которой работают. В TermHub человек сидит за другим устройством — картинка лежит в буфере его браузера, и до агента она не доходит. На телефоне нет и самой клавиши «вставить»: нужна кнопка, одна на текст и на картинки.

## Решение

Картинка загружается на хост в каталог агента `~/.termhub/paste`, а в терминал вставляется путь файла (обычной вставкой, с учётом bracketed paste). Оба агента узнают вставленный путь картинки и делают из него вложение; обычной оболочке путь тоже полезен.

- Имя файла выбирает агент, клиент называет только тип. Каталог назначения от запроса не зависит — поэтому гостю relay хватает права ввода.
- LAN — отдельный маршрут `POST /api/paste-image` с телом-файлом; relay — действие `paste-chunk` существующего кадра `FileOp`, куски по 256 КиБ.
- Входов три: кнопка в панели клавиш, событие вставки с картинкой без текста и Ctrl+V. Ctrl+V сначала читает буфер устройства; картинки нет или буфер не прочитать — в терминал уходит прежний `^V`.
- Файлы живут 7 дней, предел размера — 20 МиБ.

## Отвергнуто

- **Положить картинку в буфер хоста и послать агенту `^V`.** Работает только на macOS-хосте, затирает буфер человека, сидящего за этой машиной, и требует графической сессии.
- **Новый кадр и возможность.** Запрос редкий, ответ — одна строка; кадр `FileOp` уже умеет запрос-ответ с идентификатором. Старый агент отвечает ошибкой, её видно тостом.
- **Перехватывать Ctrl+V только на macOS.** В браузере на Windows и Linux Ctrl+V в терминале тоже уходит приложению (`^V`), а не вставляет.

## Известные ограничения

- Буфер обмена браузер отдаёт только странице в защищённом контексте (HTTPS или localhost) и после разрешения; Safari и Firefox показывают подтверждение на каждое чтение — в том числе на каждый Ctrl+V.
- Агент должен уметь узнавать путь картинки во вставке. Проверено чтением поведения Claude Code и Codex, живого прогона вставки в агента в сюите нет.
