## Что должно заработать

В `docs/adr/` появляются шесть новых ADR — `0013`…`0018`, — в которых зафиксированы
решения этого прогона. Человек, открывший репозиторий через полгода, понимает по ним,
почему терминал устроен так, а не иначе, и какие варианты были отвергнуты и почему.

Каждый ADR написан по формату существующих `0001`…`0012`: `# NNNN. <решение одной
строкой>`, затем `## Контекст`, `## Решение`, `## Почему`, `## Последствия`. В «Почему»
обязательны явные «Отвергнут вариант …» — отвергнутые варианты перечислены в спецификации.

Шесть решений (нумерация в этом порядке):

- `0013` — ядро xterm.js остаётся, своей становится обвязка (spec §1).
- `0014` — `tmux -CC` (control mode) вместо `tmux attach` (spec §2), с откатом (spec §3).
- `0015` — mosh как замена tmux отвергнут, берутся три идеи его протокола (spec §5).
- `0016` — история терминала живёт на клиенте, с лимитом и без шифрования (spec §4).
- `0017` — рамка ввода агента скрывается визуально и обратимо (spec §6).
- `0018` — совместимость протокола через объявление возможностей (spec §10).

## Разделы спецификации

Решения по реализации §1–§6, §10. Замеры — «Что измерено на живом tmux 3.7b».
Решения пользователя — `interfaces.md`, раздел «Что решено и не подлежит пересмотру».

## Критерии приёмки

- [ ] Шесть файлов `docs/adr/0013-*.md` … `0018-*.md`, имена в стиле существующих
      (kebab-case, решение в имени)
- [ ] В каждом — четыре раздела формата проекта, без лишних
- [ ] В «Почему» каждого ADR названы отвергнутые варианты с причиной отказа
- [ ] Замеры из спецификации приведены числами там, где на них опирается решение
      (83 байта на подключение, 89 байт на строку, `ESC[?1049h` первым байтом)
- [ ] «Последствия» честно называют цену: разэкранирование на горячем пути, зависимость
      от версии tmux, две дороги подключения, рост хранилища на телефоне, риск ошибки
      детектора рамки
- [ ] Ни один ADR не переоткрывает решение пользователя и не предлагает альтернативу
      тому, что уже решено
- [ ] Нет подписей инструментов, `@author`, копирайтов
- [ ] Язык — русский, строки до ~95 символов
