# TermHub — что осталось

Последняя сборка: `.autopilot/2026-11-12-native-agent-ui/` — чат: нативный интерфейс к Claude Code и Codex поверх панели tmux (27 тасков и два ремонта по приёмке; сборка открывалась дважды: после сдачи пользователь попросил доделать оставшееся после ревью, очередь и живую проверку).

## Договорились — не пересматривать

- Переписка — из транскрипта блоками, живое — с экрана (R03)
- Лента становится чатом; на плашке «Терминал» — переключатель вида; сессия с опознанным агентом открывается чатом, выбор помнится по сессии (G01)
- Экран агента узнаётся по строке ввода, а не по точному виду подвала: «просто по подвалу определять не совсем правильно, много ошибок из-за этого» (G48, ADR 0050)
- Неузнанный экран — окно терминала в границах чата, с причиной и кнопкой закрытия (R17i, G10, G15)
- Сообщения человека — слева, как ответы агента: «короткие не видно так справа» (G51, отменяет «плашкой справа»)
- Поле ввода в фокусе при любом возвращении к чату (G45, G49); на телефоне — без самопоявления клавиатуры
- «Стоп» — неброская красная кнопка в ряду иконок шапки (G36)
- Подсказки: «Свой список + сверка» (R12); opencode — лента без ввода (G08)
- Ожидающий вопрос Codex открывается кнопкой, не сам (G31)
- Работающему Codex обычный текст уходит Enter, уточнением идущему ходу: «Давай слать» (13.11.2026); слэш-команда — в очередь по Tab (G35)
- Esc для закрытия списка упоминаний чат работающему агенту не шлёт: «Все верно» (13.11.2026)
- «Стоп» — последним в ряду иконок: «Давай в конец» (13.11.2026)
- Деплой после каждого таска — relay на VPS и локальный агент (G09)
- После проверки на изолированном экземпляре тестовые сессии закрывать сразу, сервер гасить
- `/private/tmp` добавлен в корни агента по просьбе пользователя
- Вид чата пользователя устраивает: «меня устраивает сейчас что вижу»
- Почему сделано так — `docs/adr/0038`–`0050`; слова проекта — `CONTEXT.md`; замеры на живых агентах — `docs/native-agent-ui.ru.md`

Версия агента из работающей программы сверена на живых сессиях Codex
- Отправка большого запроса кусками проверена на заглушке, не на настоящем агенте (G52)
- Смена модели — через меню агента в окне терминала (G02, замер: иначе нельзя)
- Доля контекста у Claude: предел неизвестен, показывается число токенов (G03)
- Цветов вывода команд нет: транскрипты их не хранят (G30)
- У Codex нет описаний действий, событий и списка фоновых агентов, токенов в строке работы, вопросов с отметками — он их не даёт
- Работающему Codex нельзя отправить из чата неполную слэш-команду, команду с тёзками в списке и текст, кончающийся на @упоминание (G35); Esc для закрытия списка упоминаний чат не шлёт — ждёт слова пользователя
- Очередь: у Codex возвращается только последнее сообщение, у Claude — вся очередь разом; кнопки есть, только пока очередь агента совпадает с отправленным из этого чата (G40)
- Переходы между вопросами очереди Codex чат не нажимает (G31)
- Гость relay не видит миниатюр своих вложений: каталог вложений общий (G26)
- ADR и словарь не обновлялись после тасков 19–26, кроме ADR 0050; блок автопилота в `CLAUDE.md` дополнен кратко

## Известные баги

- Постановка сообщения в очередь Codex по Tab, пока в очереди ждёт вопрос, убирает вопрос — поведение самого Codex, чат его не обходит
- Возврат из очереди сверяет только число сообщений: при гонке с другим устройством вернётся и сотрётся чужое — `agent-live.ts`, `chat-composer.ts`
- Агент считается живым по существованию процесса, а не по переднему плану: остановленный Ctrl+Z агент и посторонний `node` в той же панели получат вставку — `agent-transcript.ts`
- Меню, которое красит указатель отдельно от пункта, прошло бы как строка ввода Codex (среди снимков нет) — `agent-screen.ts`
- Набранный в терминале ввод Codex «1. …» с пронумерованной второй строкой без оформления знака читается как список — `agent-screen.ts`
- Заголовок запроса разрешения Claude проверен на одном виде; другие виды и подтверждение плана откроются окном терминала — `agent-profiles.ts`
- Частично отрисованная вставка даёт ложный отказ, текст остаётся в строке агента; `/model` и `/compact` жмут Enter без повторного чтения экрана — `agent-live.ts`
- Смена режима, остановившаяся в известном, но не целевом режиме, отвечает успехом — `agent-live.ts`
- Backspace после сверки команд идёт без проверки экрана; при срыве «/» может остаться в строке — `agent-commands.ts`
- При чужом сообщении в очереди пометка «в очереди» остаётся у доставленного — `chat-composer.ts`
- Возврат в окно браузера и закрытие меню отбирают фокус у поиска по беседе и окна терминала чата — `chat.ts`
- Гость с правом ввода может вытеснить вложения владельца, залив 2 ГиБ — `paste-image.ts`
- Отметка ответа на вопрос ищется в пределах загруженной страницы; у Codex ответ записан не у всех вопросов — `transcript-feed.ts`
- Вид вставки пути с пробелами по «@» (`@"путь"`) не измерен ни на одном агенте — `chat-complete.ts`
- Плавают под нагрузкой: `relay.test.ts`, `session-link.tmux.test.ts`
