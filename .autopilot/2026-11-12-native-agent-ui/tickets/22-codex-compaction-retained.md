# 22 — Веха сжатия Codex показывает сохранённое без сжатия

**Требования:** G39
**Зависит от:** 21
**Зона:** `packages/agent/src/transcript-feed.ts` · `packages/agent/test/transcript-compaction.test.ts` · `packages/agent/test/feed-fixture.ts` · `packages/web/`
**Волна:** 16
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

У Claude веха сжатия беседы показывает, во что сжало. У Codex — только «Беседа сжата»: итог
сжатия в его транскрипте зашифрован (блок `compaction` с `encrypted_content`), поле сообщения
пусто. Зато в той же записи открытым текстом лежит то, что Codex оставил в новом окне без
сжатия: последние сообщения человека и ответы агента. Веха должна это показывать.

## Из брифа, дословно

> «А ещё в claude сжатие беседы показывает во что сжало, а в codex только "Беседа сжата". Там не получить промпт полученый?» … «давай»

## Разделы спецификации

Истории 13, 18г; `interfaces.md` — пределы страницы ленты и подробности по курсору.

## Критерии приёмки

- [ ] Названа форма записи сжатия Codex по транскриптам (без содержимого): где сохранённые сообщения человека и ответы агента, где зашифрованный итог, что лежит в поле сообщения; отличается ли запись ручного сжатия (`/compact`), если такая найдётся
- [ ] Веха сжатия Codex в ленте несёт числа сохранённых сообщений человека и ответов агента; вес страницы в пределах прежнего лимита — сами тексты в страницу не кладутся
- [ ] Раскрытие вехи по курсору отдаёт сохранённые сообщения (человек и агент, в порядке беседы) в пределах лимита подробностей с пометкой обрезки; служебные инструкции (роль разработчика, описания инструментов) не отдаются; зашифрованный итог не отдаётся
- [ ] Запись сжатия весом в мегабайты читается без загрузки файла целиком в память сверх окна чтения ленты; запись, не влезшая в окно, даёт веху без раскрытия, а не ошибку
- [ ] В чате веха — строка «Беседа сжата · сохранено без сжатия: N и M» с раскрытием по тапу в список сообщений с оформлением; нет сохранённого — прежняя «Беседа сжата»
- [ ] Если поле сообщения записи непусто — показывается оно, как у Claude; веха сжатия Claude не изменилась
- [ ] На обоих транспортах тело одно (общая фикстура, нейтральный текст); строки в обоих словарях; `tsc` агента и веба чист
