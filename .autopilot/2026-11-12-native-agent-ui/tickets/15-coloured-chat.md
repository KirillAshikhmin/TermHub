# 15 — Цвет в чате, как в терминале агента

**Требования:** G30
**Зависит от:** 14, 16
**Зона:** `packages/web/` · `packages/agent/src/transcript-feed.ts` · `packages/agent/test/transcript-detail.test.ts` · `packages/agent/test/transcript-events.test.ts` · `packages/agent/test/feed-fixture.ts`
**Волна:** 13
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

В терминале Codex вывод цветной: команда подсвечена по синтаксису, «Ran / Running / Exited
(status 1)» различаются цветом и точкой, выделения и цитаты в тексте ответа цветные. В чате
всё одним цветом. Чат должен быть цветным так же — красками темы TermHub.

## Из брифа, дословно

> «а ещё в кодексе вывод цветной. Можно так же в чате сделать?»

## Разделы спецификации

Истории 13, 15, 15а, 16, 16а.

## Критерии приёмки

- [ ] Команда оболочки в строке действия и в раскрытии подсвечена по синтаксису существующей подсветкой проекта (команда, ключи, строки, перенаправления); длинная команда в строке обрезается, подсветка не ломается
- [ ] У действия цветная метка исхода: выполнено, выполняется, завершилось с ошибкой — с кодом выхода, когда транскрипт его несёт; названо, какие поля исхода есть у Claude и у Codex, а каких нет
- [ ] В раскрытом выводе команды цвета ANSI отрисованы, если транскрипт хранит их; если не хранит — названо прямо, вывод остаётся одноцветным
- [ ] В тексте ответа выделение, цитата, встроенный код и ссылки имеют различимые цвета из переменных темы; жёстких цветов вне темы нет
- [ ] В светлой и тёмной теме контраст текста на фоне чата не ниже 4.5 для каждого из новых цветов (проверено расчётом по переменным темы)
- [ ] Текст транскрипта попадает в DOM только через `textContent` и узлы подсветки — без `innerHTML`; управляющие последовательности, кроме цветовых, отбрасываются
- [ ] Лента без чата не изменилась; `tsc` агента и веба чист
