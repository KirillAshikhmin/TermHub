**Требования:** R06, G01, R07, R08, R09, R04, G08, R19i, R18i, G09
**Зависит от:** 01
**Зона:** `packages/web/`
**Волна:** 2
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Вкладка ленты становится чатом. В полосе разделов у сессии с Claude или Codex вместо кнопки
ленты — переключатель «Терминал / Чат»; такая сессия открывается чатом, остальные терминалом,
ручной выбор помнится по сессии на устройстве. В чате переписка выглядит как в приложении
Claude: сообщения человека плашкой справа, ответ агента во всю ширину с оформлением markdown,
действия свёрнуты строками и раскрываются в команду с выводом или diff, ссылки и пути
кликабельны. Поле ввода, полоса состояния и окошко терминала придут следующими тасками — для
них в оболочке оставлены места. Транспорт получает все методы чата сразу (LAN и relay), чтобы
следующие таски не делили эти файлы.

> «Да, давай ленту преобразуем. Тогда у вкладки терминала не просто кнопочка, а переключатель вида.» · вид при входе — «Чат, если агент опознан» · opencode — «Оставить ленту без ввода» · на что похож чат — «Приложение Claude»

## Критерии приёмки

- [ ] `Transport` получил `live`, `act`, `commands`, `feedDetail`, `pasteFile` на LAN и relay; relay-запросы коррелируются по `id`, срок ответа 10 с, опоздавший ответ не достаётся чужому запросу
- [ ] У сессии с опознанным Claude или Codex и возможностью `chat` в полосе разделов стоит переключатель «Терминал / Чат»; отдельной кнопки ленты нет
- [ ] Без возможности `chat`, в сессии opencode и в сессии без агента переключателя нет, вкладка ленты прежняя
- [ ] Вход в сессию с агентом открывает чат, без агента — терминал; ручной выбор помнится по сессии и переживает перезагрузку; другая сессия не затронута
- [ ] Переключение вида не пересоздаёт терминал и не рвёт его канал
- [ ] Сообщение агента отрисовано markdown: заголовки, списки, таблица, цитата, код с подсветкой и копированием; недописанный блок кода не ломает сообщения ниже
- [ ] Сообщение человека — плашка справа, ответ агента — во всю ширину; на ширине 360 px горизонтальной прокрутки страницы нет
- [ ] Действие — строка «инструмент: аргумент»; тап раскрывает команду с выводом или diff с цветом строк; идёт загрузка — индикатор; отказ — строка ошибки с «Повторить»; `pending` — «ещё выполняется»
- [ ] https-ссылка открывается в новой вкладке; путь внутри разрешённых корней открывает файл в проводнике; гостю без `files` и для пути вне корней — обычный текст
- [ ] Агент есть, беседы нет — пустой чат с приглашением написать запрос; агент вышел — «агент не запущен» и переход в терминал
- [ ] Обрыв связи оставляет переписку на экране
- [ ] Поиск по ленте, «искать дальше», прыжок к находке из общего поиска и тумблер мышления работают в чате как раньше
- [ ] У низа переписка прокручивается за новыми записями сама; выше — кнопка «к последнему»
- [ ] Строки добавлены в оба словаря i18n; `tsc` по вебу без новых ошибок; `libsodium` в LAN-бандле нет
