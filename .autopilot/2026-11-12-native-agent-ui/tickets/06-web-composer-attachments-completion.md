# 06 — Веб: поле ввода, вложения и подсказки

**Требования:** R14, G04, R11, G06, R12, R13, G09
**Зависит от:** 03, 05
**Зона:** `packages/web/`
**Волна:** 4
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

В чате появляется своё поле ввода, как в приложении Claude: многострочное, с черновиком по
сессии, вложениями над текстом и кнопкой отправки. Отправленное сразу видно в переписке и
заменяется записью транскрипта; пока агент работает, запрос встаёт в его очередь. К запросу
прикладываются картинки и любые файлы — путь в тексте и миниатюра. По «/» открывается список
команд агента с описаниями, по «@» — файлы проекта; список сужается по набору.

## Из брифа, дословно

> «строкой ввода с изображениями и слэш команды с подсказами и автокомплит в поле ввода, ну и соответсвенно нативное поле ввода запроса»

> автокомплит — «Свой список + сверка» · вложения — «Путь в текст, но но с миниатюрами и добавлением файлов» · «Очередь сообщений»

## Критерии приёмки

- [ ] Поле многострочное, растёт до предела высоты и дальше прокручивается; на телефоне стоит над клавиатурой и не перекрывает переписку
- [ ] Enter отправляет или переносит по настройке `enterSends`; кнопка отправки неактивна на пустом поле; пока отправка идёт, вторая не начинается
- [ ] Отправленное стоит в переписке с пометкой «отправляется»; запись из транскрипта заменяет его без дубля
- [ ] Отправка при работающем агенте помечена «в очереди» до появления в транскрипте
- [ ] Отказ или обрыв: сообщение помечено ошибкой, «Повторить» шлёт заново, «Вернуть в поле» возвращает текст
- [ ] Отказ `stale` из-за текста в строке агента показывает выбор: забрать текст в поле (`take-input`) или отправить поверх
- [ ] Черновик и пути вложений переживают перезагрузку и переключение сессий; у каждой сессии свой
- [ ] Картинка прикладывается из буфера, выбором файла, с камеры и перетаскиванием; произвольный файл — выбором и перетаскиванием
- [ ] У вложения миниатюра (у не-картинки значок и имя) и путь в тексте; убрал миниатюру — путь из текста исчез; идёт загрузка — индикатор; отказ — тост с причиной
- [ ] Пока вложение грузится, отправка ждёт; запрос не уходит без пути
- [ ] «/» в начале поля открывает список команд с подсказками и источником; набор сужает; стрелки, Tab, Enter и тап подставляют; Esc закрывает и агенту не уходит; нет совпадений — списка нет
- [ ] Команда не из списка отправляется как набрана
- [ ] «@» открывает файлы каталога сессии, набор сужает, выбор вставляет путь; гостю без `files` список не открывается
- [ ] `completionAt`, `rankCommands`, `applyCompletion` — чистые функции с тестами на края: «/» в середине текста, «@» после пробела, каретка внутри слова
- [ ] У гостя без `write` поля ввода нет
- [ ] Строки в обоих словарях; `tsc` по вебу без новых ошибок; `libsodium` в LAN-бандле нет
