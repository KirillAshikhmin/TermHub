# 08 — Экран Claude с фоновыми агентами узнаётся

**Требования:** G13, G15, G16
**Зависит от:** 01
**Зона:** `packages/agent/src/agent-screen.ts` · `packages/agent/src/agent-profiles.ts` · `packages/agent/test/fixtures/screens/` · `packages/agent/test/agent-screen.test.ts` · `packages/agent/test/agent-profiles.test.ts` · `packages/protocol/src/chat.ts` · `packages/protocol/test/`
**Волна:** 6
**Ревью:** нет
**Модель:** сильная

## Что должно заработать

Пользователь открыл чат на живой сессии Claude, которая ведёт фоновых агентов, — чат
переключился на окошко терминала и не возвращается. Воспроизведено: экран такой сессии
распознаётся как неузнанный. Под подвалом Claude стоит список фоновых агентов, в подвале —
добавки «1 shell», «← 2 agents», «↓ to manage». Снимки, на которых строилось распознавание,
делались без фоновых агентов. Такой экран должен читаться как ожидание ввода или работа.

## Из брифа, дословно

> «Возможно из-за › Message from @general-purpose (ctrl+o to expand) окно переключилось в режим терминала и не хочет возвразаться назад, сейчас так в этом чате. разберись почему.»

## Разделы спецификации

Истории 38, 52–55, 55а.

## Критерии приёмки

- [ ] Причина названа одной строкой: какое именно правило распознавания отвергало экран со списком фоновых агентов
- [ ] Снимок экрана работающего Claude со списком фоновых агентов под подвалом и добавками в подвале («N shell», «← N agents», «↓ to manage») лежит фикстурой (обезличенный) и читается как `working` с режимом из подвала
- [ ] Тот же экран в ожидании ввода (без строки работы) читается как `idle`; с текстом в строке ввода — `idle` с `input`
- [ ] Список фоновых агентов любой длины от 1 до 10 строк не меняет вердикт; его строки не попадают ни в `input`, ни в `status`, ни в очередь
- [ ] Строка переписки «› Message from @… (ctrl+o to expand)» над строкой ввода не принимается ни за ввод, ни за вопрос
- [ ] Вопрос и запрос разрешения на экране со списком фоновых агентов распознаются с тем же `stamp`, что без списка
- [ ] Прежние отказы сохранены: оболочка, пустой экран, обрезанный пополам снимок — `unknown`; все прежние тесты снимков зелёные
- [ ] `ScreenState` получил необязательное поле `why: string`; на каждом `unknown` `readScreen` заполняет его короткой английской причиной — какое правило не сошлось (например `no input frame`, `footer not recognized`, `content below footer`), без текста с экрана
- [ ] На снимках оболочки, пустого и обрезанного экрана причины разные и названы; на узнанных экранах поля нет
- [ ] Подвал Claude вида «⏵⏵ auto mode on (shift+tab to cycle) · ⧉ index · ← 2 agents» (подсказка в скобках после режима, пункт «⧉ <имя>», счётчик агентов; без списка под подвалом и с ним) читается как `idle` либо `working` с режимом `auto`
- [ ] Незнакомый пункт подвала после узнанного режима (любой текст между разделителями «·») экран неузнанным не делает
