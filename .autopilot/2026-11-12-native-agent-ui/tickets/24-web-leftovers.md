# 24 — Доделки в вебе: вкладка, камера, повтор, метки, фокус

**Требования:** G41, G43, G44, G45
**Зависит от:** 20, 21, 22
**Зона:** `packages/web/`
**Волна:** 17
**Ревью:** нет
**Модель:** сильная

## Что должно заработать

Два новых замечания пользователя и веб-часть оставшегося после ревью. Нажатие на вкладку
текущей сессии переключает чат на терминал — не должно. На Mac кнопки «прикрепить» и
«камера» открывают одно и то же окно выбора файла — камера на десктопе лишняя.

## Из брифа, дословно

> «А ещё почему-то при клике на вкладку текущую в списке вкладок с чата переключает на терминал, а не надо так.»

> «Правда на маке кнопка прикрепить файл и камера открывают окно открытия файла.»

> «И делай что осталось после ревью.»

## Разделы спецификации

Истории 11а, 28а; раздел «Доделки после сдачи (G41)».

## Критерии приёмки

- [ ] Причина названа: почему нажатие на вкладку уже открытой сессии уводит с чата на терминал (куда ведёт ссылка вкладки, кто решает вид)
- [ ] Нажатие на вкладку текущей сессии — в полосе вкладок, в боковой панели и в панели по стрелке — оставляет открытый вид; переход на другую сессию открывает её в её запомненном виде (чат для сессии с агентом по умолчанию)
- [ ] Кнопка камеры показывается только на устройствах с грубым указателем (телефон, планшет); на десктопе её нет; на телефоне она по-прежнему открывает камеру
- [ ] Повтор отправки после потерянного ответа шлёт действие с тем же ключом идемпотентности, что и первая попытка (необязательное поле `key` действия; если агент ключа ещё не знает — поведение прежнее); прежняя проверка «дошёл ли запрос» остаётся
- [ ] Метка «выполняется» у строки действия обновляется, когда результат приходит с приращением переписки, без раскрытия
- [ ] Подсказки по «@» находят и вставляют файлы с пробелами в имени (вставка в том виде, который агент принимает, — назови какой)
- [ ] Автосворачивание окна терминала ставит фокус в поле ввода, только если фокус был на странице вообще нигде или внутри окна терминала; из поиска, палитры и окна настроек не отбирает
- [ ] Контекст и расход после перехода на сессию показывают значение не позже первого опроса (не ждут 30-секундного таймера); на ширине телефона подпись контекста не обрезана
- [ ] Сетевой сбой загрузки миниатюры не запоминается как отказ навсегда: при возврате связи миниатюра запрашивается снова
- [ ] Строки в обоих словарях; `tsc` веба чист; прежние тесты зелёные
- [ ] Переключение вида на «Чат», переход на вкладку другой сессии, открытой чатом, и возврат на раздел чата из проводника, репозитория или Gradle ставят фокус в поле ввода чата; на устройствах с грубым указателем — по правилу проекта для терминала (ADR 0010: фокус без самопоявления экранной клавиатуры); гость без поля, открытое окно настроек, палитра и поле поиска фокус не теряют
