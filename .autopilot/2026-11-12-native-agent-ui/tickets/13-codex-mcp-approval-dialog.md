## Что должно заработать

В сессии Codex чат ушёл в окошко терминала с причиной «footer not recognized». На экране —
запрос разрешения Codex на вызов инструмента MCP: «Allow <сервер> to run "<инструмент>"?»,
варианты «1. Allow / 2. Allow for this session / 3. Always allow / 4. Cancel», подвал
«enter to submit | esc to cancel». Такой диалог в замерах не встречался. Он должен стать
карточкой запроса разрешения с кнопками.

## Критерии приёмки

- [ ] Причина названа: какое правило отвергало экран с этим диалогом
- [ ] Обезличенный снимок диалога лежит фикстурой; `readScreen` отдаёт `permission` с заголовком, телом (сервер, инструмент, аргументы, как их рисует Codex) и четырьмя вариантами с клавишами; указатель на текущем варианте распознан
