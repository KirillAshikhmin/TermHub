# 23 — Доделки на агенте: клавиши, распознавание, права, данные

**Требования:** G41
**Зависит от:** 19, 22
**Зона:** `packages/protocol/` · `packages/agent/`
**Волна:** 17
**Ревью:** да — клавиши и права
**Модель:** сильная

## Что должно заработать

Пользователь попросил доделать то, что осталось после ревью. Это известные дефекты агентной
части чата из отчёта сборки: клавиши, уходящие без достаточной сверки; распознавание, которое
может принять не то за вопрос; права гостя; данные ленты.

## Из брифа, дословно

> «И делай что осталось после ревью.»

## Разделы спецификации

Раздел «Доделки после сдачи (G41)»; `PROGRESS.md` — «Известные баги».

## Критерии приёмки

- [ ] Отправка запроса: между вставкой и клавишей отправки экран перечитывается, и клавиша уходит, только если на экране по-прежнему строка ввода с вставленным текстом, а не диалог; всплывший запрос разрешения клавишу не получает — отказ `stale`
- [ ] Список команд: запрос, который шлёт клавиши сверки, не доступен по GET с чужой страницы — сверка запускается только запросом, проходящим проверку Origin (чтение готового списка остаётся GET); оба транспорта и веб согласованы
- [ ] Отпечаток вопроса различает тела, отличающиеся пробелами внутри строки (`rm -rf / tmp/x` и `rm -rf /tmp/x`), и остаётся прежним при переносе по ширине панели; прежние снимки `*-narrow` зелёные
- [ ] Диалог без указателя ни на одном варианте (кроме вопроса с отметками, где указатель бывает на отправке) не читается как запрос разрешения; экран с нумерованными пунктами без признаков вопроса из профиля остаётся `menu` либо `unknown`
- [ ] `interrupt` на экране `unknown` клавиш не шлёт и отвечает отказом; на открытом вопросе очереди Codex — не шлёт Esc (отказ с понятным текстом)
- [ ] Смена режима, попавшая в режим вне профиля, продолжает цикл до целевого в пределах измеренного числа режимов и не оставляет агента в неизвестном режиме молча: отказ называет фактический режим
- [ ] Смена активной панели посреди действия — отказ, а не успех; после клавиши очереди (Tab) успех только при узнанном экране с пустой строкой ввода
- [ ] Подробности действия отдаются для каждого инструмента строки транскрипта Claude, а не только первого (курсор записи различает их)
- [ ] Гость relay без права `files` не получает через раскрытие действия вывод команд и содержимое правок — только строку действия; с правом `files` — как сейчас
- [ ] У каталога вложений есть общий предел (по умолчанию 2 ГиБ): при превышении старейшие файлы убираются до загрузки нового; картинка по пути отдаётся потоком или кусками без чтения 20 МиБ в память на LAN
- [ ] Веха сжатия Codex длиннее окна чтения даёт веху без раскрытия, а не пропадает
- [ ] Действие чата несёт необязательный ключ идемпотентности: повтор с тем же ключом в течение 2 минут клавиш не шлёт и возвращает прежний результат (пакет протокола, оба транспорта)
- [ ] Причина падения двух тестов «источники Linux: /proc» в `agent-transcript.test.ts` найдена: устранена, если она в коде или тесте; названа, если в машине
- [ ] Прежние тесты зелёные без ослабления ожиданий; `tsc` агента чист
