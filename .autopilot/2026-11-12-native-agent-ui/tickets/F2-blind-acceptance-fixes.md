# F2 — Ремонт по слепой приёмке доделок

**Требования:** G40, G45, G49, G48
**Зависит от:** —
**Зона:** `packages/web/`
**Волна:** 20
**Ревью:** нет
**Модель:** сильная

## Что должно заработать

Слепая приёмка доделок нашла три расхождения с тем, что просил пользователь. Все три — в вебе.

## Из брифа, дословно

> «Правка и отмена сообщений в очереди - давай сделаем.»

> «При переключении на чат или между кладками пусть поле ввода всегда будет в фокусе» · «И после закрытия превью и любого возвращения на экран с чатом - фокус должен быть в поле ввода»

> «Как будет просто по подвалу определять не совсем правлиьно, много ошибок из-за этого»

## Разделы спецификации

Истории 21в, 21д, 27в, 66.

## Критерии приёмки

Находки приёмки, дословно:

- [ ] «Изменить»/«Отменить» сообщения в очереди: сообщение остаётся в переписке с пометкой «отправлено», хотя снято. Браузер, заглушка Codex, 3 из 3 (2× «Изменить», 1× «Отменить»). Журнал запросов: «808ms CLICK edit → 1022ms live q=null → 1286ms act:unqueue» — опрос экрана внутри действия успевает показать пустую очередь. **Починено, когда:** после успешного `unqueue` локальная запись снятого сообщения убрана из переписки («Отменить») либо убрана с переносом текста в поле («Изменить») и не помечается ни «отправлено», ни «доставлено», как бы ни пришёл опрос экрана во время действия.
- [ ] Телефон 390×800: после первого открытия терминала сессии и возврата в чат фокус уходит из поля ввода в скрытое поле xterm — 2 из 2 сессий (в поле на 300 и 700 мс, не в поле с 1500 мс и далее). Повторные переключения — 3 из 3 в поле. **Починено, когда:** скрытый терминал сессии не забирает фокус после своего первого монтирования, пока показан чат; фокус чата остаётся в поле ввода (тихий на устройствах с грубым указателем).
- [ ] Агент вышел при открытом чате: в шапке остаётся «Агент работает», строки «Агент не запущен» на экране нет; показано «В этой панели не работает ни Claude, ни Codex, ни OpenCode». **Починено, когда:** при ответе `no-agent` на опрос состояния шапка чата не называет агента работающим, чат показывает «агент не запущен» с переходом в терминал, поле ввода неактивно; агент вернулся — чат оживает сам.
