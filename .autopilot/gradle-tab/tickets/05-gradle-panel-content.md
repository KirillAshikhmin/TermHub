## Критерии приёмки

- [ ] Конфигурации запуска — отдельным списком над тасками; нет ни одной → секции нет вовсе
- [ ] Дерево тасок: корневой проект первым, подпроекты по алфавиту; группы в порядке от Gradle, «Other tasks» последней; таски внутри группы по алфавиту; описание — подписью
- [ ] Поиск фильтрует по имени и описанию, совпадение подсвечено; ничего не нашлось — так и написано
- [ ] Пока список собирается — «Читаю таски проекта…», а не пустой экран; кнопка «Обновить» перечитывает
- [ ] Gradle не отдал список → текст ошибки с хвостом stderr + «Повторить»; ручной ввод имени таски остаётся доступен и работает
- [ ] Поле аргументов рядом с кнопкой запуска; выбор конфигурации подставляет в него её `scriptParameters`; конфигурация из нескольких тасок запускается одной командой в порядке из XML
- [ ] Запуск при уже идущей сборке спрашивает «Остановить и запустить» / «Отмена», а не запускает молча
- [ ] «Недавние» — до 10 последних запусков этой сессии (таски + аргументы), повтор одним нажатием, хранится в localStorage
- [ ] Гость без права записи видит список, но не может запустить — кнопки нет, а не «нажал и ошибка»
- [ ] Шов 3 (`packages/web/test/gradle-view.test.ts`): `groupTasks` на многомодульном наборе, `filterTasks` (совпадение/пусто), рендеры строки таски и строки конфигурации
- [ ] Все новые строки — через i18n, ключи есть и в `ru`, и в `en`
- [ ] `npx tsc -p packages/web/tsconfig.json --noEmit` чист; `npx vitest run` зелёный; `npm run build` собирается
