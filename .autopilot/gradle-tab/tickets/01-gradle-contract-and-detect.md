## Что должно заработать

Агент умеет ответить про папку три вещи: Gradle это или нет; какие в проекте есть
таски (включая таски подпроектов многомодульной сборки, с группами и описаниями);
какие в проекте есть конфигурации запуска Gradle. Ничего ещё не запускается и
никуда не отдаётся по сети — но всё это покрыто тестами и вызывается из Node.

## Из брифа, дословно

> «Но только если открытая папка является Gradle проектом»
> «На вкладке выбор таски для запуска, да и вообще все достепные конфигурации запуска, как о ни в IDEA отображаются»

## Критерии приёмки

- [ ] Типы из «Контракта» в `interfaces.md` объявлены в `packages/protocol/src/frames.ts`, плюс `FrameType.Gradle = 41` и `GradleResult = 42`
- [ ] `detectProject(dir)` находит `settings.gradle`, `settings.gradle.kts`, `build.gradle`, `build.gradle.kts`, `gradlew`; сообщает, исполняем ли wrapper; для обычной папки возвращает `null`
- [ ] `listTasks(dir, {refresh})` запускает `<wrapper|gradle> tasks --all --console=plain -q` через login-оболочку (`$SHELL -lc`, строка КОНСТАНТНАЯ, cwd = папка проекта), таймаут 180 с
- [ ] `parseTasksOutput` разбирает вывод в `GradleTasks`: таски подпроектов (`:app:assembleDebug`) отнесены к своему проекту, группы сохранены в порядке печати, «Other tasks» последней, описание таски подхвачено
- [ ] Список кэшируется в памяти по (папка → mtime build-файлов); `refresh: true` сбрасывает кэш
- [ ] Ошибка Gradle возвращается как ошибка с хвостом stderr (не молчанием и не пустым списком)
- [ ] `listRunConfigs(dir)` читает `.run/*.xml`, `.idea/runConfigurations/*.xml` и `RunManager` из `.idea/workspace.xml`; берёт только `type="GradleRunConfiguration"`; достаёт `name`, `taskNames` (в порядке из XML), `scriptParameters`, `externalProjectPath` (с подстановкой `$PROJECT_DIR$`)
- [ ] Конфигурация, чей `externalProjectPath` после realpath оказался вне корня сессии, пропускается; дубли по имени схлопываются, `.run` важнее
- [ ] Битый/огромный XML пропускается, остальные конфигурации возвращаются (лимиты: 100 файлов, 256 КБ на файл, 4 МБ на `workspace.xml`)
- [ ] `buildSessionName(session)` даёт `_gradle_<санитизированное ≤24>_<6 hex sha256>`, укладывается в `^[\w-]{1,40}$`, детерминирован; `isBuildSessionName` его узнаёт
- [ ] Валидация: имя таски `^[A-Za-z0-9:._\-]{1,200}$`, аргумент `^[A-Za-z0-9:._=,\/@+\-]{1,200}$`, не более 32 аргументов; непрошедшее ОТВЕРГАЕТСЯ, а не экранируется
- [ ] Шов 1 (`packages/agent/test/gradle.unit.test.ts`) покрывает: парсер тасок на многомодульном выводе, парсер XML на трёх источниках + битом файле, детект на временном каталоге, имя сборочной сессии, валидацию
- [ ] `npx vitest run` зелёный целиком
