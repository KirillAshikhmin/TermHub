## Что должно заработать

Агент умеет запустить набор тасок в отдельной tmux-сессии, сказать, идёт ли сборка
сейчас, и остановить её. Сборочная сессия переживает всё, кроме явного убийства, и
не показывается пользователю в списке сессий. Проверяется на изолированном сокете,
без настоящего Gradle.

## Из брифа, дословно

> «с возможностью их запуска и выводом в отдельном терминальном окне н иже в этой же вкладке»
> «что бы видеть что выводится при сборке»

## Критерии приёмки

- [ ] `startRun({session, dir, tasks, args, socketName})` создаёт сессию `new-session -d -s <buildName> -c <dir>` БЕЗ команды (tmux поднимает login-оболочку) и отправляет строку через `send-keys -t '=<имя>:' -l` + `send-keys … Enter`
- [ ] Командная строка ровно: `<./gradlew|gradle> <таска…> <аргумент…>; printf '\n[termhub] gradle exit=%s\n' $?`; флагов консоли от себя не добавляется
- [ ] Цель tmux пишется как `=<имя>:` (с двоеточием) — форма без двоеточия не находится
- [ ] Нет ни `./gradlew`, ни `gradle` в PATH login-оболочки → запуск отвергается с внятной ошибкой, сессия не создаётся
- [ ] Запуск при уже идущей сборке не происходит молча: `startRun` без `force` возвращает состояние `running`; с `force` — останавливает прежнюю и запускает новую
- [ ] Завершившаяся сборка НЕ убивает сессию: остаётся оболочка с выводом, `runStatus` даёт `finished`; следующий запуск переиспользует или пересоздаёт эту сессию
- [ ] `runStatus` отличает `idle` (сессии нет) / `running` (в панели идёт не оболочка) / `finished`
- [ ] `stopRun` шлёт `C-c`; повторный вызов при всё ещё живой команде убивает сессию (`kill-session`)
- [ ] `SessionService.list()` не отдаёт сессии, которые узнаёт `isBuildSessionName`; поллинг звонков их тоже не видит
- [ ] Все вызовы tmux — `execFile` без shell, сокет прокидывается снаружи (`socketName`), хардкода `termhub` нет
- [ ] Шов 2 (`packages/agent/test/gradle.tmux.test.ts`) на изолированном сокете `-L termhub-test-<uniq>` с `kill-server` в teardown: запуск команды-пустышки, статус `running` → `finished`, стоп, скрытие из `list()`
- [ ] `npx vitest run` зелёный целиком
