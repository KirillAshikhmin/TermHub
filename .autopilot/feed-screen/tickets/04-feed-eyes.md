# 04 — Лента глазами человека

**Требования:** R04, R08, R03, G01
**Blocked by:** 02, 03
**Зона:** `packages/web/src/feed.ts`, `packages/web/src/theme.css`, тесты ленты
**Волна:** 4
**Status:** ready

Нарезан по слепой приёмке, которая прошла по экрану в браузере. Тесты и ревью этого не
видели: всё найденное видно только глазами.

## Что должно заработать

**1. Прыжок оставляет отметку.** Сейчас переход к найденному месту работает — лента
переезжает на нужную дату, — но запись, к которой прыгнули, ничем не отличается от соседей.
Приёмка замеряла фон десять раз по 120 мс после нажатия: тот же `rgb(22,27,34)`, что у
соседних, вспышки нет. Подсвечена только строка в списке находок. Человек попадает в
середину экрана и не понимает, на какую из десятка записей.

**2. Ярлык инструмента не дублируется.** Везде «Bash Bash cd …», «exec exec python3 …»,
«Agent Agent Слепая приёмка», «Skill Skill autopilot». Агент кладёт имя инструмента и в поле
`tool`, и первым словом `text` — экран показывает оба.

**3. Строка инструмента — одна строка.** Показывается сырая склейка
`cd … && git add … && git commit -q -F - <<'EOF' …`, которая переносится на две-три строки и
занимает больше места, чем реплика человека рядом. По решению пользователя это «одна строка
что сделал», а не содержимое.

**4. Поиск покрывает вехи.** Фраза из записи вида `note` в беседе есть (проверено запросом к
агенту), а экран отвечает «Просмотрена вся беседа, ничего не нашлось».

**5. Находки не переживают фильтр.** Снятие галки «Мышление» убирает запись из ленты, а её
строка остаётся в списке находок и ведёт в никуда.

## Из брифа, дословно

> «с поиском и переходом к месту»

> «вызов инструмента одной строкой „что сделал“»

## Критерии приёмки

- [ ] После прыжка видно, к какой записи попал: отметка держится достаточно, чтобы её заметить, и гаснет сама
- [ ] Отметка проверена **в браузере**, а не только тестом: сказано, чем она видна и сколько живёт
- [ ] Имя инструмента показано один раз
- [ ] Строка инструмента занимает одну строку; длинное обрезается, а не переносится
- [ ] Поиск находит текст записей всех видов, включая вехи
- [ ] Находка, скрытая фильтром, из списка уходит или ведёт себя честно — не притворяется живой
- [ ] Прежние утверждения тестов целы; на каждое исправление есть проверка, красневшая до него
