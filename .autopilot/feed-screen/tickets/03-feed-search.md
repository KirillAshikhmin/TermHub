# 03 — Поиск по ленте и переход к месту

**Требования:** R03, R03.1, R04
**Blocked by:** 02
**Зона:** `packages/web/src/feed.ts` (поиск и прыжок), `i18n.ts`, `theme.css`
**Волна:** 3
**Status:** ready

## Что должно заработать

Сверху ленты — поиск. Находки списком: время, вид записи, строка вокруг совпадения.
Нажатие переносит ленту к тому месту беседы и подсвечивает запись.

Поиск сначала идёт по загруженному — мгновенно, без сети. Не нашлось — дочитывает ленту
назад страницами и честно говорит, сколько записей просмотрел.

## Из брифа, дословно

> «с поиском и переходом к месту»

## Разделы спецификации

Истории 9–11; Решения §4.

## Критерии приёмки

- [ ] Поиск по загруженному отвечает без сети; регистр не различается
- [ ] Не нашлось — дочитывание назад страницами до `bof` или до предела, с числом просмотренных записей на экране
- [ ] Нажатие на находку тянет `around(entry.cursor)` и показывает запись в окружении
- [ ] Найденная запись подсвечена, подсветка гаснет сама
- [ ] Запись без `cursor` (веха склейки) не предлагается как точка прыжка
- [ ] Строки поиска — через `i18n`, оба словаря
