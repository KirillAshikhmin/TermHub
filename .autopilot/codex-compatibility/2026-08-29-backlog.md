# Очередь после текущего захода

## R11 — Открыть файл на хосте

> «И ещё фича в очередь: при открытии файла в Проводнике есть кнопка Открыть в NotAText - добавь так же просто кнопку Открыть на хосте, которая открывает файл там, где запущена сессия, в частности на моем мак.»

Статус: отложено по формулировке пользователя «в очередь»; в текущую реализацию
совместимости с Codex не входит.

Граница будущей реализации: действие должно выполняться агентом на хосте сессии,
работать только для разрешённого пути этой сессии и использовать системное открытие
файла (на macOS — приложение по умолчанию), не передавая локальный путь браузеру.
