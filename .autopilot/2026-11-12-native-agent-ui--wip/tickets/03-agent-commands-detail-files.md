## Что должно заработать

Агент TermHub отдаёт всё, чего не хватает чату сверх экрана: список слэш-команд агента сессии
(встроенные из профиля, пользовательские и проектные команды и навыки с диска, разовая сверка
с тем, что агент показывает по «/»); подробности действия по раскрытию — команда с выводом,
diff правки; занятость контекста в расходе; загрузку любого файла, не только картинки.

## Из брифа, дословно

> «слэш команды с подсказами и автокомплит в поле ввода» · «вывод сообщений от консоли с всем форматированием, командами и т.д.» · «строкой ввода с изображениями»

> автокомплит — «Свой список + сверка» · инструменты — «Строкой, раскрытие по тапу» · вложения — «Путь в текст, но но с миниатюрами и добавлением файлов» · «Контекст и расход»

## Разделы спецификации

Истории 15–18, 28–34, 50; «Решения по реализации» — подробности действия, список команд,
контекст, вложения; `interfaces.md` — «Провод», строки `agent-commands.ts`, расширения
`transcript-feed.ts`, `transcript-usage.ts`, `paste-image.ts`.

## Критерии приёмки

- [ ] `GET /api/commands` и кадр `Commands` отдают одно тело: встроенные команды профиля, команды и навыки из пользовательского и проектного каталогов агента сессии, у каждой — имя, подсказка, источник
- [ ] Каталога команд нет, файл команды без описания, битый frontmatter — список собирается без них, запрос не падает
- [ ] Сверка с экраном идёт только при экране `idle` с пустой строкой ввода; после неё строка агента пуста; команда, которой не было в списке, добавлена с источником `screen`; результат сохранён на хосте по агенту и версии и второй раз клавиши не шлются
- [ ] Сверка невозможна (агент занят, в строке текст) — список отдаётся с `verified: false`, клавиши не отправлены
- [ ] Гость без `write` получает на `Commands` отказ `forbidden`
- [ ] Запись `tool` страницы ленты несёт признак наличия подробностей; вес страницы прежний
- [ ] `feed` с `detail=<курсор>` отдаёт для Bash команду и вывод, для Edit и Write — diff по строкам, на обоих агентах; на обоих транспортах тело одно
- [ ] Вывод длиннее 64 КиБ обрезан с `truncated`; действие без результата отдаёт `pending`; курсор не на действии или чужой — `cursor-stale`
- [ ] Расход несёт `context` (занято и предел, где транскрипт их даёт); старые поля расхода не изменились
- [ ] Загрузка файла произвольного типа по LAN и по relay кладёт его в каталог вставок с правами 0600 и возвращает путь; имя выбирает агент, расширение берётся из исходного имени и очищается; файл больше 50 МиБ отвергается; прежняя вставка картинки работает как раньше
