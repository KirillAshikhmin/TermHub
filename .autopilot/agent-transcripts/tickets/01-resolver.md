## Что должно заработать

Модуль отвечает на один вопрос: какой агент работает в этой панели tmux и где лежат файлы
его беседы. Ничего не читает по содержанию, ничего не показывает.

## Из брифа, дословно

> «как при полноэкранном режиме … сделать историю, хотя бы персонально для конкретных
> приложений (claude, codex)»

> «Определитель „панель → файл транскрипта“ в агенте … явная деградация при незнакомом
> формате. Без интерфейса.»

## Разделы спецификации

Всё: «Что измерено», истории, depth pass, «Решения по реализации» §1–§6, «Границы и швы».

## Критерии приёмки

- [ ] Для панели с Claude файлы находятся через реестр запущенных процессов, привязка по
      адресу панели, а не по заголовку, каталогу или времени файла
- [ ] Для панели с Codex файлы находятся среди открытых процессом, выбирается корневой
      поток, вложенные отбрасываются
- [ ] Запись реестра с чужим временем старта процесса не принимается: переиспользованный
      pid не подставляет чужую сессию; учтено, что в реестре время в UTC, а у системы локальное
- [ ] Отказ различим по причине: агента нет, формат незнаком, определить не удалось из-за
      прав или недоступного обхода. Пустой результат вместо причины не отдаётся никогда
- [ ] Цепочка беседы собирается назад по признаку продолжения и отдаётся от начала к
      текущему файлу; при обрыве — признак «начало не найдено», а не молчание
- [ ] Путь, пришедший из реестра, проверяется на принадлежность каталогам агентов текущего
      пользователя; чужой путь — отказ, а не чтение
- [ ] Дорогой поиск кэшируется на панель, ключ включает pid и время его старта, смена
      процесса сбрасывает запись; есть способ сбросить кэш целиком
- [ ] Ничего не блокирует надолго и не падает: битый JSON, отсутствующие поля, незнакомый
      формат адреса панели, недоступный каталог — всё это штатные ответы
- [ ] Тесты идут на подменённых источниках: реестр, список открытых файлов, файловая
      система. Настоящие агенты и настоящий tmux не запускаются
- [ ] Каждый тест был бы красным без своего куска логики — проверь мутацией и скажи, что снимал
- [ ] `npx vitest run packages/agent/test/` без новых падений, `npm run build -w @termhub/agent` чисто
