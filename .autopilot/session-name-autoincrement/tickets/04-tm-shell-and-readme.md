## Что должно заработать

В терминале IDE набираю `tm` без аргумента в папке `MyProject`; сессия `MyProject` уже
есть — создаётся `MyProject1`, потом `MyProject2`, по тому же правилу, что в вебе. `tm <имя>`
и `tml` не меняются: явное имя по-прежнему «присоединиться или создать». Пользователь с
уже прописанным блоком `# termhub` в `~/.zshrc`/`~/.bashrc` получает новый `tm`, повторно
запустив `termhub setup`: тот находит устаревшее однострочное определение и предлагает
заменить только его. README (en + ru) описывает правило именования для «+» и `tm` и больше
не утверждает, что `tm` создаёт сессию `main`.

## Из брифа, дословно

## Критерии приёмки

- [ ] `tmFunction(socket = TMUX_SOCKET)` строит текст функции; `TM_FUNCTION = tmFunction()`; POSIX sh (bash и zsh), без `local`, переменные с префиксом `_th_`
- [ ] Без аргумента: база `basename "$PWD"` (как сейчас, без санитизации); кандидат занят, если дословно есть в `tmux -L <сокет> list-sessions -F '#{session_name}'` (точное сравнение строки; нет сервера = свободно) — **не** `has-session -t "="`, см. D01; пока занят — следующий `<база><n>`, n = 1, 2, …; затем `tmux -L <сокет> new -s <кандидат>`; с аргументом — `new -As "$1"` без изменений; `tml`/`tmc` не тронуты
- [ ] Живой тест шелла (`sh -c`, подложный `tmux`-скрипт в `PATH`, который помнит «занятые» имена и логирует аргументы): занято `MyProject` → `new -s MyProject1`; заняты `MyProject`,`MyProject1` → `MyProject2`; свободно → `MyProject`; `tm foo` → `new -As foo`; проба идёт через `list-sessions -F '#{session_name}'` с `-L <сокет>`; папка `foo.bar` при занятом `foo.bar` → `new -s foo.bar1`; папка с пробелом в имени уходит в `new -s` одним аргументом (лог подложного tmux — по аргументу на строку)
- [ ] `upgradeTmFunction(existing: string) -> string | null`: заменяет прежнюю однострочную `tm() { … }` новым определением, остальной текст байт в байт; старой строки нет → `null`; уже новое определение → без изменений; тесты в `setup.test.ts`
- [ ] `maybePatchShellRc`: маркер есть, текущего `tm` нет → `Update tm? [Y/n]`, при согласии — замена только этой строки; нераспознано или отказ — печать нового определения с просьбой вставить вручную; маркера нет — как раньше, добавить блок целиком
- [ ] README.md и README.ru.md: правило именования для кнопки «+» и `tm` (`MyProject` → `MyProject1` → `MyProject2`), «`tm` создаст/откроет сессию `main`» исправлено на имя папки; как вернуться в существующую сессию (`tml`, `tm <имя>`); обе версии синхронны по смыслу
